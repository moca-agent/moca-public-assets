# MOCA public assets

Public brand assets used in MOCA email templates. Only files approved for public
access belong in `docs/`. Do not add application code, credentials, invitation
codes, user data, or internal documents.

GitHub Pages publishes the `docs/` directory from `dev/jieming.li`.

## Email banner

- URL: https://moca-agent.github.io/moca-public-assets/email/ambr-banner-v1.png
- Format: PNG, 1120 × 120 (display at 560 × 60 desktop pixels)
- Source: approved AMBR artwork, with vertical whitespace cropped for email

Published asset paths are permanent. Add `v2`, `v3`, etc. for changes; do not
replace or remove older versions because previously sent emails still use them.

Emails reference the public HTTPS URL directly, without attaching the PNG.
